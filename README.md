# 应用目录迁移工具

这是一个 Windows 桌面工具，用于扫描注册表中的已安装应用目录，将选中的目录迁移到其他磁盘，并在原位置创建 NTFS Junction。程序仍然访问原路径，实际文件则存储在目标磁盘。

也可以在“自定义链接”页迁移任意普通目录，例如把 `C:\temp` 的实际内容存储到其他磁盘。

应用列表会读取注册表中的应用图标。点击任意应用后，左侧详情栏会显示完整源目录、版本、发布者和注册表位置；长路径支持换行、滚动和选择复制。

应用大小优先读取卸载注册表项的 `EstimatedSize`；缺失时会在后台统计应用目录。点击“大小”表头可以按容量排序。

## 运行

需要 Windows 10/11 和 Python 3.13+。项目使用 `uv` 管理 Python 和依赖：

```powershell
uv sync
uv run app-migrate
```

界面使用 `PySide6-Fluent-Widgets`，支持 Windows 11 Mica、系统浅色/深色模式和系统强调色。该组件对非商业项目采用 GPLv3；商业分发前需要从组件作者处取得商业授权。

## 使用注意

- 迁移前请关闭目标应用以及可能占用目录的后台进程。
- 不要迁移 Windows、用户主目录、磁盘根目录或正在使用的系统目录。
- 扫描结果来自注册表，路径是否适合迁移仍需用户确认。
- 跨盘迁移会先复制并校验，再替换源目录；创建链接失败时会自动恢复源目录。
- 迁移过程中不要关机，也不要手动删除带 `.app_migrate_backup_` 或 `.app_migrate_partial_` 的临时目录。

## 工作方式

1. 从当前用户和本机的 32/64 位卸载注册表项读取应用信息。
2. 根据 `InstallLocation`、卸载命令和图标路径识别现存目录。
3. 使用 `robocopy` 将内容复制到目标盘的中间目录并校验文件数与总字节数。
4. 临时重命名源目录，创建指向目标目录的 NTFS Junction。
5. 验证链接后删除源盘备份，释放空间。
