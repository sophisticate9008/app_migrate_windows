# 应用目录迁移工具

这是一个 Windows 桌面工具，用于扫描注册表中的已安装应用，并识别其程序目录、当前用户数据、漫游数据和公共数据目录。程序本体与应用数据在独立页面中迁移，并分别在原位置创建 NTFS Junction；程序仍然访问原路径，实际文件则存储在目标磁盘。

也可以在“自定义链接”页迁移任意普通目录，例如把 `C:\temp` 的实际内容存储到其他磁盘。

“应用迁移”页只显示程序本体；“数据迁移”页把每个本地用户数据、漫游用户数据和公共应用数据目录单独列为一行，可以只勾选 C 盘数据而不迁移已经安装在其他盘的程序。点击任意条目后，左侧详情栏会显示完整路径和相关信息。关联数据目录按应用名、发布者和可执行文件名匹配，只采用实际存在的精确目录，不会迁移同一厂商的其他产品目录。

程序会区分普通目录和 NTFS Junction：普通目录标记为“可迁移”；已经链接的目录标记为“已迁移”、禁止重复勾选，并在侧边详情中显示当前链接目标。

应用大小优先读取卸载注册表项的 `EstimatedSize`；缺失时会在有限时间内统计应用目录，超时项显示 `-`，避免扫描大型目录时阻塞过久。安装时间优先读取 `InstallDate`，缺失时使用应用目录创建日期。点击表头可以按名称、大小或安装时间排序。

程序首次打开时会自动扫描一次，无需手动点击“扫描注册表”。

“应用迁移”会去掉源盘盘符并保留其余完整目录结构。例如 `C:\11\22` 选择 `D:\migrate` 后，实际文件保存到 `D:\migrate\11\22`。“数据迁移”按应用分别保存为 `应用目录\UserData`、`RoamingData` 或 `SharedData`。三个迁移页面会分别记住最后选择的目标目录。

## 运行

需要 Windows 10/11 和 Python 3.13+。项目使用 `uv` 管理 Python 和依赖：

```powershell
uv sync
uv run app-migrate
```

克隆项目后可以直接双击根目录中的 `启动应用迁移工具.vbs`。它会按当前位置查找项目，首次启动时自动隐藏运行 `uv sync`，之后请求管理员权限并直接打开 GUI，整个过程不显示终端窗口。Python 程序入口也会检查权限，因此通过 `uv run app-migrate` 等其他方式启动时同样会弹出 UAC 请求；提权后的 GUI 和迁移期间调用的系统工具均不会创建控制台窗口，拒绝提权后程序不会以普通权限继续运行。

也可以运行 `scripts\install_shortcut.ps1` 创建桌面快捷方式。快捷方式指向项目中的便携启动器，因此重新创建虚拟环境后不需要重新生成。

界面使用 `PySide6-Fluent-Widgets`，支持 Windows 11 Mica、系统浅色/深色模式和系统强调色。该组件对非商业项目采用 GPLv3；商业分发前需要从组件作者处取得商业授权。

## 使用注意

- 程序启动时需要管理员权限，以便移动受保护目录并创建 NTFS Junction。
- 迁移前请关闭目标应用以及可能占用目录的后台进程。
- 点击迁移后，程序会先扫描所选应用的运行进程；检测到前台或后台进程时会阻止迁移，并允许关闭应用后重新检测。
- 不要迁移 Windows、用户主目录、磁盘根目录或正在使用的系统目录。
- 扫描结果来自注册表，路径是否适合迁移仍需用户确认。
- 跨盘迁移会先复制并校验，再替换源目录；创建链接失败时会自动恢复源目录。
- 文件统计、复制校验和临时目录清理支持超过 Windows `MAX_PATH` 的深层目录。
- 迁移过程中不要关机，也不要手动删除带 `.app_migrate_backup_` 或 `.app_migrate_partial_` 的临时目录。

迁移期间底部会显示当前阶段文字和 Fluent 圆形忙碌指示器，不会再显示细线进度条。

## 工作方式

1. 从当前用户和本机的 32/64 位卸载注册表项读取应用信息。
2. 根据 `InstallLocation`、卸载命令和图标路径识别现存目录。
3. 在“应用迁移”和“数据迁移”页分别列出程序本体与关联数据，用户按目录独立选择。
4. 使用 `robocopy` 将每个目录复制到保留层级或对应数据分类的临时路径，并校验文件数与总字节数。
5. 将原目录临时改名为备份，再把临时路径切换为最终目标目录。
6. 在原路径创建指向目标目录的 NTFS Junction；程序仍访问原路径，数据实际位于目标盘。
7. 验证 Junction 指向正确后删除源盘备份，释放空间；此前任一步失败都会尝试恢复原目录。
